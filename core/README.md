# Core

协议基础与节点工具，不代表已经实现分布式共识。

- `protocol.py`：32 位 UUID 分片、内容摘要、钱包公钥地址与签名验证。
- 节点通过 `https://blockchain.xialiwei.com` 获取挑战、认证、登记与查询。
- 地址为 `fd1_` + SHA-256，签名算法第一版采用 RSA-3072 / SHA-256 / PKCS#1 v1.5，以兼容 Unity 内置密码学 API。不是 Ethereum 钱包，也不用于保存资产。
- `/v1/nodes/me` 返回自己的登记信息，`/v1/nodes` 返回主动同意公开的有效节点；`/v1/games/{game_id}/peers` 仅向该局成员返回参与节点的 IP 与端口。
- 登记 IP:PORT 是声明，不证明端口可达。NAT 穿透、中继、共识、区块互验、P2P 同步与成员协商尚未实现。
- 服务器观察到的 IP 仅从可信反代转发信息提取；公开 IP 需节点明确选择发布。

密码学扑克的洗牌密钥与登录钱包不是同一套密钥。禁止将钱包私钥提交给服务器或写入链上。
