# Unity 客户端

用 Unity 6.6 / 6000.6.2f1 打开 `HOTPOOR_Poker` 子目录，打开 `Assets/Scenes/WalletDesk.unity`，点击 Play。

场景包含桌面、坐姿眼高摄像机和钱包面板。仅为身份原型，尚无完整对局。

1. 输入两次密码，创建加密钱包 JSON。
2. 文件在项目根目录 wallet/；Windows 构建版在游戏 exe 旁的 wallet/。
3. 复制兼容钱包文件后刷新，从列表单选一个钱包。
4. 输入密码，在线获取挑战并在本机签名。
5. 验证成功后本次测试会话仅用此钱包，结束测试会话后才可切换。

服务配置：`Assets/Resources/client-config.json`。默认域名尚需部署；不可达时不会假装登录成功，本地创建和备份仍可用。
密码不上传，JSON 不含明文私钥；复制后仍需原密码。密码遗失不能由服务器重置解密。钱包不是其他链的资产钱包。
目录不可写会报错，不偷偷换目录。备份文件不得提交 GitHub。
签名时私钥会短暂存在进程内存中；正式发布前需文件权限、内存与平台安全审查。
