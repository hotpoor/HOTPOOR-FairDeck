# HOTPOOR扑克 · 游戏规划

> 最新机制以 [游戏机制 v0.1](GAME_MECHANICS.md) 为准；本文保留早期范围建议。

## 已确定

- 游戏名称：HOTPOOR扑克。
- 项目位于 仓库根目录（Unity 项目现位于 apps/unity/HOTPOOR_Poker）。
- 使用本机已安装的 Unity 6.6（6000.6.2f1）开始开发。
- 先共同规划，再逐步做出第一版。

## 首先一起决定

1. 核心玩法：斗地主、德州扑克，还是自定义规则？
2. 第一版玩家在哪里玩：Windows 桌面，还是浏览器？
3. 第一局和谁玩：电脑对手、本机轮流操作，还是远程朋友？
4. 氛围：轻松朋友局、传统牌桌，还是有故事与角色的扑克游戏？

## 第一版范围建议（待确认）

先做一种玩法、一张牌桌，以及完整的一局流程：

进入游戏 → 开始新局 → 发牌 → 玩家按规则行动 → 判定胜负 → 展示结果 → 再来一局。

最先保证牌面清楚、操作明确、规则正确。具体人数、牌数、行动方式、胜负条件，在选择玩法后补齐。

建议第一阶段使用本地对局验证规则；联网、账号、长期成长系统和商业化分别讨论后再安排。

## 开发里程碑建议

- 第一步：写清规则，并用几组示例牌局确认理解一致。
- 第二步：实现独立的牌、牌组、洗牌发牌与规则判定逻辑。
- 第三步：制作可以点击操作的牌桌，打通一局完整流程。
- 第四步：根据选定模式加入电脑对手或多人连接。
- 第五步：调整视觉、音效与操作反馈，导出第一份可试玩版本。

每一步以“能实际试玩和验证什么”为验收依据。

## 体验原则建议

- 玩家看得清当前局面、轮到谁以及可以做什么。
- 规则与结果透明，尊重玩家的时间与自主选择。
- 先做小而完整、好玩的体验，再决定是否扩大规模。
